# GradePilot

GradePilot is a Python and Streamlit web app being developed for the CCSC Midwest 2026 Hackathon. It helps students understand their current grade and explore the scores they need to reach a target letter grade.

Students manually enter the grading rules from their syllabus and their scores so far.

## Installation and Running

Python and pip are required.

1. Clone this repository and open its folder in a terminal.

2. Install the dependencies:

   `python -m pip install -r requirements.txt`

3. Start the application:

   `python -m streamlit run app.py`

4. Open the local address displayed in the terminal.

## How to Use

1. Enter the grading policy from your syllabus.
2. Add your completed scores and attendance.
3. Mark remaining items as not yet taken.
4. Review your current grade and the calculation breakdown.
5. Enter assumed scores for remaining work to explore target grades.
